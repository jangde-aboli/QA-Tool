# QA_Scoring
AI-Powered QA Tool using LLM and RAG
Tools: Python, LLMs, RAG, Prompt Engineering, Embeddings
• Built a QA tool to score PDF documents using RAG-based LLMs and prompt engineering;
automated manual QA processes improving efficiency and consistency across workflows
• Designed document retrieval pipeline using vector embeddings for context-aware, structured
outputs built for scalability and seamless integration with existing client workflows
**You need to make a client seceret file which will have auth creds to run this**
